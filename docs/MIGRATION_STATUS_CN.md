# WaveDispX 0.2 迁移与验收报告

## 结论

WaveDispX 0.2 在已声明范围内已经形成完整闭环：配置 → 离散波数法正演 → 主动炮集或真实混合噪声记录
→ NCF → phase/FJ/Hankel 频散 → 连续拾取 → Rayleigh/Love 理论曲线 → 图件和机器可读结果。
MATLAB 不再是运行依赖，只作为 golden 数据生成器。

## 数值等价性

`matlab_reference/golden_dwm_kernels.h5` 由
`matlab_reference/export_python_goldens.m` 导出，自动测试覆盖：

- 16 组频率—波数位置的 SH 与 P-SV 全局复刚度矩阵；
- 水平载荷 `HR/HT/HV` 和竖直载荷 `VR/VV` 的完整 f-k Green 函数；
- 五个时空 Green 分量的逆 Hankel 合成；
- Ricker 卷积后的五分量主动炮集；
- 有限混合记录 NCF；
- phase-shift 频散能量。

主要数组容差为 `2e-10` 到 `2e-8` 相对误差；自动回归同时覆盖规则线阵快速路径、任意二维
接收器逐对相关、Notebook 分步/全流程一致性和缓存作废规则。加速
FJ/Hankel 使用可关闭的核查表：步长 0.002 时，完整主动 Rayleigh 图相对逐点精确特殊函数
的 L2 误差为 `3.94e-7`，最大绝对能量差 `2.41e-6`，738 个频率列的峰值位置 100% 一致。
设 `processing.radial_kernel_lookup_step=0` 可回到逐点精确路径。

## 正演与处理流程

推荐运行 `notebooks/WaveDispX_workflow.ipynb`。它既可在单元格输入全部参数，也可读取 TOML；
既能逐阶段显示结果，也能一键全盘执行。预检、命令行和 Notebook 共用同一配置解析、离散波数法正演、
混合噪声、互相关和频散函数，不存在一套“演示计算”。正演开关默认关闭。只需输入审核时，
仍可使用不运行波场正演的 `notebooks/preflight_review.ipynb`。

主动源：C++ 动刚度组装和小型复线性方程求解 → f-k Green 函数 → 逆 Hankel 得到五个
源力—位移分量 → Ricker 卷积 → 线阵炮集 → FJ/Hankel 或 phase-shift 成像 → 基阶连续
拾取和多模理论曲线。

被动源有两条共存路径。`vertical`：C++ 计算竖直点力 Green 函数；
`three_component`：C++ 计算 RR/TT/ZR/RZ/ZZ 全 Green 张量，每个源激发独立全局 Fx/Fy/Fz，
按源—接收器方位旋转、传播并旋回接收 X/Y/Z。两条路径随后都执行：层状模型径向网格合成
→ 插值到真实源检距 → 各源独立有限窗随机频谱乘 PSD 与 Green 传递函数 → 接收器处混合
→ 只使用混合记录做 receiver-receiver 互相关。3C 线阵/面阵按台站对方位得到 RR/TT/ZZ NCF，
再输出 ZZ、RR、联合 Rayleigh 与 TT Love 分量图。

使用的受控数值优化只有三项，并全部留有误差记录：

1. 层状模型 Green 函数的径向插值；正式算例运行时抽查精确距离，L2 误差 `0.00476`。
2. FJ/Hankel 核查表插值；可设为 0 关闭，并有精确路径自动测试。
3. 被动窗流式相关；所有源先混合，不保留逐源时域响应，也不做逐源内部互相关。
4. 多分量联合 Rayleigh 是各分量单独归一化频散图的 RMS；RR/ZZ 原图同时保存，联合图不替代
   原始分量证据，也不参与 Green/NCF 生成。

## 频散质量与收敛

主动完整算例：Rayleigh/Love 多模理论邻域的主峰占比分别为 99.86%/100%，基阶拾取 MAE
分别为 1.94/1.25 m/s。Love 图的强能量分支是理论高阶模态，不能按“偏离基阶”误判为假频。

被动 1800 s：理论模态邻域主峰比例 100%，基阶拾取 MAE 0.80 m/s，RMSE 1.39 m/s，
自动质量验收通过。相对 1800 s 最终结果：

| 累积时长 | 独立窗 | NCF L2 差 | 频散图 L2 差 | 拾取 MAE 差 |
|---:|---:|---:|---:|---:|
| 60 s | 3 | 0.806 | 0.635 | 1.177 m/s |
| 600 s | 30 | 0.216 | 0.149 | 0.346 m/s |
| 1800 s | 90 | 0 | 0 | 0 |

这说明原始 NCF 在 60 s 仍明显波动，但主频散脊已可识别；600 s 后拾取已很接近 1800 s，
1800 s 用作稳定展示和最终验收。

## 已知边界

- 模型是一维水平层状介质，不支持二维/三维横向变化或自由表面地形；
- 接收系统可为等间距水平直线阵列、参数化二维 grid 或 CSV 定义的任意二维地表阵列；
  后两者在被动处理中按
  台间距分箱并作径向平均，不保留台站对方位，暂不用于方位各向异性成像；
- 被动支持竖直快速路径和物理 Fx/Fy/Fz 三分量环境力；3C 输出 TT/Love 能量图，但当前自动拾取
  仍以联合 Rayleigh 基阶为主；
- 合成噪声窗相互独立，因此 `noise.overlap` 当前必须为 0；
- `stationary_gaussian` 和 `poisson_ricker` 是可控统计模型，不等同于某个具体现场的全部噪声机制。

## 高阶模态专项验收

`scripts/benchmark_high_mode_models.py` 用同一主动观测系统比较多组速度模型。最终高阶基准采用
5 m 的 Vs=180 m/s 表层、15 m 的 Vs=300 m/s 中层和 Vs=600 m/s 半空间：

- 主动 ZZ 对第二条高阶的理论曲线支持率为 0%，RR 为约 96%；RR/ZR/RZ/ZZ 联合后其中位
  归一化能量约 0.51，约 69% 有效频点不低于 0.35；
- 被动正式基准使用 192 个物理 3C 源、133 道、1800 s/90 窗。600→1800 s 的 NCF 与主
  phase-shift 频散相对 L2 分别为 0.163/0.223；说明基本阶已经稳定，而高阶仍受模态激发、
  分量耦合和有限孔径控制，继续增加时长不会把物理弱模态自动变强；
- Bessel/FJ 和 Hankel 对第一、第二高阶的支持高于 phase-shift，但在线阵有限孔径上旁瓣也更强。
  因此三方法对照是敏感性检查，不是“挑一张最亮的图”作为结果。
