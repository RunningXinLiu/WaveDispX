# 可迁移频散能量正演规范

版本：1.0.1；日期：2026-09-17；状态：工作规范已固定，科学流程尚未全面验收。

适用：当前1D ISO、Rayleigh主导有限台阵任务。其他物理场景需要新协议和相应验证，不能自动继承。

本目录可整体复制到Linux、macOS、Windows或其他项目。内容不依赖原电脑绝对路径、不捆绑私有求解器、不假设SSH别名或Conda环境存在。**可迁移的是契约和修改规则，不是已经封装好的跨平台求解器。** 当前实验脚本仍含项目路径，移植时按下述接口分离；未宣称这些重构已完成。

## 在新项目使用

1. 将本目录放到项目 `docs/forward_workflow/`，先读 [WORKFLOW_zh.md](WORKFLOW_zh.md)。
2. 将下列段落加入该项目的AGENTS.md；使用其他工具时，将同段加入其项目指令或开场请求。仅复制文件不能保证所有工具自动读取。
3. 将 `runtime.example.json` 复制为本机的 `runtime.local.json`，填写真实路径、启动器和获分配资源；本地运行文件加入.gitignore，不提交凭证。
4. 建立项目自己的物理配置、证据登记和实验目录。示例中的null表示未配置，不是默认值；缺项检查通过前不能运行。
5. 迁移旧实验时同时携带配置、源样点、接收坐标、原始输出及SHA256清单；单独复制此规范不等于携带验证证据。

### AGENTS.md可直接复制的入口

```text
涉及频散能量正演、成像、数据生成或相关代码修改时，先读
 docs/forward_workflow/WORKFLOW_zh.md 和项目当前状态/证据登记。
按其中的科学契约、平台配置分离和变更验证规则执行。
规范版本不等于科学验收；不得跨模型、源、算子或权重继承通过结论。
保留用户显式输入；未获支持的配置显式报错，不静默换模型或算子。
修改后记录影响范围、配置/代码哈希及回归证据，交付可查看的QC图。
```

## 维护与同步

本目录为可迁移契约入口；项目历史实验和共享长文提供案例证据。变更应先更新WORKFLOW及CHANGELOG，再更新各副本；用版本和SHA256辨别，不按文件时间猜最新。发生冲突保留两版并说明差别，遵守用户当前明确指令，不静默合并科学设置。
