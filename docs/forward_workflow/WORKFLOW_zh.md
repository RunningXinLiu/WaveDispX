# 频散能量正演与代码变更契约

契约版本：1.0.1；2026-09-17。文档状态：已采用；生产验收状态：未完成。

## 1. 固定主线与适用边界

- SASEM：直接频域受迫响应→实际接收点复响应→明确成像算子，作为快正演主线。不以画理论根、非相干孔径功率或合成波形替代该主产品。
- 首个标准成像：保留道间振幅的定向phase shift／直接空间FT，台阵窗显式配置。当前Hann是有记录的研究设置，不是所有geometry的万能默认。
- F-J/F-H：成像对照；如改作训练输入，更新观测协议并重新核查，不只换名称。
- SPECFEM2D：代表性模型独立波场验证，需匹配点源/线源/轴对称等物理定义，不能认为所有“2D”自然等价。
- WaveDispX：独立内核交叉检查及复杂源场/PSD/观测压力测试；原生源平滑和频率窗原样登记，匹配适配器独立命名。
- 主动点源与被动噪声源场分开；接收器加噪不是噪声源分布模拟。ISO/Rayleigh不以VTI/Love/Biot证据替代。

## 2. 分离四类配置

|配置|必备内容|迁移规则|
|---|---|---|
|物理实验|层厚/Vp/Vs/rho/半空间/Q、单位、源时空定义与样点、分量、台站坐标、边界物理、目标f/c轴|一个配置供应各求解器；用户输入优先，不静默改动|
|观测算子|傅里叶符号、时间原点/窗/滤波、gamma、台阵权重、核、方向、归一化/下限、输出量|属于数据标签定义，不能藏在绘图函数|
|数值方案|各求解器离散阶数、网格、dt、PML、积分上下限/步长、记录长度等|允许求解器不同，但须独立检查其收敛|
|平台运行|工作目录、求解器/解释器路径、启动器、CPU/MPI/GPU分配、远程连接|单独runtime配置；不得改变前三类语义|

使用SI单位，保存实际轴与坐标，不只保存min/max。区分用户输入、估计候选、已在具体范围通过的参数。null/缺失不能自动补成貌似合理的常数。训练的geometry/f-c范围按任务和模型族设计，不按隐藏真值逐样本自适应泄漏答案。

## 3. 成像定义必须可复算

约定U_j(f)使用exp(-i2πft)时间变换，源台偏移r_j与传播方向明确。定向平面波叠加：

A(f,c)=Σ_j w_j U_j(f) exp(+i2πf r_j/c)，P(f,c)=|A(f,c)|²。

记录w是否归一化、Hann/等权或其他形式。P为成像功率，不等同完整物理能流。不存在未声明的额外“power weight”。旧FK代码若就是该空间求和，在符号统一后等价；二维FFT网格/插值FK需单独登记和核查。

当前历史F-J/F-H实现为：A=ωk Σ_j h_j q_j U_j K(kr_j)，k=ω/c，q_j为归一化r_j*dr_j；K分别为J0、H0(1)、H0(2)。这仅描述本项目历史实现，不代表所有同名算法。旧phase_shift取正负方向幅值较大者，和定向结果分开命名。

相位归一化U/|U|会改变观测，必须记录epsilon的绝对/相对定义和触发比例。旧“amplitude_preserving”分支含95分位公共缩放，返回图还逐频峰值归一化，不能当绝对振幅。

exp(-gamma*t)是时间权重；Omega=omega-i*gamma须与上述时间变换约定配套。它改变观测，既不是材料Q也不是纯显示。gamma=0目标不能靠删除元数据、后期改色标或直接取消收敛所需正则化来实现，需独立收敛验证。任意到时窗也不自动等价于直接频域响应。

Hankel类型按时间符号和传播方向确定，保留反向诊断但不凭好看选核。逐频各自归一化会把极弱反向输出拉亮，必须同时检查未归一化幅值。

## 4. 执行顺序与标签准入

1. 冻结模型、源、阵列和目标产品，读当前证据，建立唯一实验ID。保存原始输入与来源。
2. 根据模型族、源支持和目标深度/分支确定频带、速度域；检查边缘能量，实际增加f/c求值点检查采样。理论根只用于诊断，保留截止/漏模态信息，不把根序号自动当跨模型身份。
3. 台距与孔径分别检查；群到时、源持续和尾波估计记录时长，再看实际完整道集与近中远道。SPECFEM保存真实面波窗及截窗前后波形；窗不能保证体波/面波完全分开时明说。
4. 按影响因素独立检查数值：SASEM的p/PML/k/正则化，SPECFEM的网格/dt/边界/时长，WaveDispX的周期/采样/源平滑。变化时重验受影响范围，不机械重跑所有旧案例。
5. 在同源、同接收点、同观测算子下比较求解器；原生不同产品单列，不用误差数字混作求解器精度。禁止拟合时移/增益促成一致。
6. 输出人工QC：模型、源/源谱、geometry、实际波形/窗（波形链）、无覆盖和理论覆盖图、差图、逐频指标、耗时和未通过项。直接展示主要图，不能只给标量。
7. 只有对该目标观测、模型/采集范围的所需检查有证据时，才将该范围标为可用于生产。图不清晰可作为已声明的观测压力测试；数值错误不能当训练噪声。原始数据、掩码、干扰参数和随机种子保留。

指标须在检查前定义：复响应误差、原始功率误差、逐频形状、弱峰/峰位分别记录。明确分母和聚合方式；max_f相对L2不是整图平均误差，更不是地下速度误差。图像W1等不证明反演唯一性。任何候选1%门槛不是通用认证，不在看结果后放宽。

## 5. 通用代码接口与变更规则

以下为移植/重构契约，不表示全部旧脚本已经实现：

- 求解器适配层：接收物理配置、数值配置、runtime；返回带单位/轴/符号/来源的复接收谱，或原生波形及时间轴。未支持的源、分量或几何显式报错。
- 观测层：接收波形/复谱及完整算子配置，输出原始复成像幅值与线性功率；不可依赖隐藏全局路径或静默修改输入。
- 显示层：只读取结果，保存归一化参考、dB公式与裁色范围；不改写原始数据，不用平滑制造一致。
- QC层：读取冻结输入与结果，输出逐项指标、适用范围、通过/失败/待查及证据路径。状态过时应查日志和数组，不把后处理失败当正演未完成。

修改类别及必要检查：

|修改|必须执行|
|---|---|
|路径/启动器/平台|检查环境和权限、源版本、输入输出哈希；小型基准数值一致性。浮点库变化按事先声明容差核查，不强求数组位级一致|
|重构/性能优化|固定输入比较原始复谱、成像输出、轴/单位/符号；记录运行资源和性能，不只比PNG|
|核/窗/方向/归一化/gamma|新operator版本和新结果目录；同一输入重成像对照；失效的是受影响观测的旧验证，不能无声继承|
|源/模型/采集/数值|新实验配置和哈希；重新设计/验收相关数值与物理范围；不覆盖旧数据|
|仅显示|确认原数组哈希未变，检查色标/参考是否可比，保留未覆盖版；无需无理由重跑正演|

保留上游原版、补丁/适配器、文件散列和许可来源，不静默改vendor。规范用版本号+CHANGELOG记录；不兼容的观测语义改动升级主版本。协议版本、代码版本和科学验收状态是三个独立字段。

无需每次 routine 修改重新征求已给出的授权；但发现影响科学含义的未知输入时应明确提出，而不是自行猜成“已验证默认”。

## 6. 最小可交接产物

建议每次实验保存config.json、operator.json、provenance.json、原始数组、qc/report.json、可查看图和REPORT.md；名称可适配项目，内容不可缺。provenance包含实验ID/父实验ID、契约/代码/求解器版本、输入输出SHA256、启动命令和资源、软件环境、随机种子。不要保存密码/token。

证据登记逐项包含：检查ID、物理及观测配置哈希、比较变量/取值、覆盖频带与模型、指标/阈值/依据、实际结果、证据路径、状态、待查项。仅写“已通过”不够。

## 8. 九层案例更新及向反演交接（2026-09-17）

九层案例：8有限层+半空间，130m界面，15–25m低速层，801节点10–810m/1m，4–40Hz/.25，共145实际频率；模型和源只属该受控案例，不能复制成通用默认。证据：`runs/iso_nine_layer_v1/REPORT_zh.md`。四频率20项积分/PML/同物性细分/k截断/台距控制最大变化0.006432%。原dc1最坏峰功率差20.10%；主图dc.25在40Hz对dc.125仍差1.0727%，不称全面收敛。本九层模型尚无独立SEM/WaveDispX验收。

每份实质性结果须同页展示模型层参数、源/谱、geometry及成像定义；同时提供无覆盖图和清晰有图例的理论曲线覆盖图。理论根只作诊断，不能根据根掩去离根能量或把它自动命名为泄漏波。显示修改核验原始数组哈希，不重跑正演。

进入conditional flow前冻结目标参数到完整模型的映射（含厚度改变时相邻层/界面的规则）、先验、已知条件和未知干扰。所有样本使用预先声明的共同采集/坐标，不能根据隐藏真值改变网格。接收噪声须经过同一实际成像算子；旧理想图独立高斯接口不自动兼容。成像数值差需与同观测噪声尺度比较；未验收的数据只能标明诊断，不能静默转成生产训练标签。
